A data-driven decision system connecting skill profiles, career requirements, and priority scoring into an actionable learning roadmap.

02

The Question

The premise for PathWise emerged from a specific, recurring obstacle in student development.

Students often know where they want to go without knowing which skill should come next.

The gap between a current profile and a career target isn't a single missing piece; it's a web of prerequisites, varying skill weights, and prioritization choices. I wanted to build a system that calculated that path instead of guessing it.

03

Data & Logic

The core of the project was a Python logic engine. Before any frontend was built, the conceptual math of a "Skill Gap" and "Career Fit" had to be defined mathematically.

Current Level + Required Level → Gap
Gap = max(Required Level - Current Level, 0)
GapScore = Gap / 4 × 100
Measuring how far a current skill level is from the required proficiency.
Current Level + Required Level + Importance → Career Fit
SkillMatch = min(Current Level / Required Level, 1) × 100
CareerFit = weighted average of SkillMatch by Importance
Evaluating overall alignment with a potential career track.
Gap Score + Importance + Market Demand + Strategic Value → Priority
Priority = 0.30 × GapScore + 0.30 × Importance + 0.20 × Market Demand + 0.20 × Strategic Value
Determining the true next step algorithmically.
Prerequisites → Recommendation Eligibility

Only skills with Gap > 0 are candidates. An unmet prerequisite blocks that skill from recommendation.

05

Product

The logic was only half the project. To make it useful, it had to be accessible.

I led the development of the frontend implementation, turning the Python backend into a working data-driven web application. The interface translates complex gap analyses and priority scoring into an intuitive Learning Roadmap.

The UI respects the complexity of the data without overwhelming the user, focusing purely on the "next step" rather than exposing the entire calculation matrix.

06

Validation

A recommendation engine is only as good as its edge-case handling. The implementation was validated through end-to-end testing.

  • E2E Calculation Trace: Verified that priority scoring matched theoretical models perfectly.
  • Prerequisite Blocking: Confirmed that high-priority advanced skills were correctly suppressed if foundational skills were missing.
  • Full Stack Integration: Automated testing ensured the frontend correctly connected to and parsed the Python logic output.
07

Takeaway

PathWise demonstrated the ability to take a conceptual problem (learning direction) and solve it systematically: a system that moves from profile → analysis → prioritization → recommendation → roadmap.
