# Tùng Anh Portfolio — Design Brief

## Identity

Name: Nguyễn Tùng Anh

Current status:
Third-year student at Foreign Trade University (FTU)
Major: International Business Economics

Core identity:
THE ARCHITECT × THE CONDUCTOR

Core statement:
"I build systems that turn complexity into something that works."

Supporting statement:
Business. Technology. Performance.

## Portfolio Positioning

This is not a conventional student CV website.

The portfolio should communicate a person who:
- understands complex systems
- structures information
- builds practical solutions
- coordinates people, technology and processes
- performs under real-world constraints

The narrative should move through:

OBSERVE → STRUCTURE → BUILD → COORDINATE → EXECUTE

## Design Language

Editorial × Architectural × Technical × Refined

The website should feel:
- intelligent
- composed
- premium
- cinematic
- structured
- slightly mysterious
- contemporary
- human

Avoid:
- generic SaaS dashboards
- excessive rounded cards
- excessive glassmorphism
- neon cyberpunk
- gaming UI
- excessive gradients
- template-like portfolio layouts
- overly decorative animations
- childish/student-project aesthetics

Display:

Body / UI:
Jost

Use typography as a major visual element.

Large editorial headings.
Strong contrast between display typography and functional interface text.
Avoid excessive font weights.

## Graphic Language

Use a recurring node / line / path system.

The visual metaphor represents:
- business workflows
- software architecture
- signal routing
- career paths
- decision systems

The motif should evolve throughout the website rather than appear as random decoration.

The site should feel like one continuous editorial experience rather than separate generic website sections.

## Motion

Motion should communicate systems and flow.

Use:
- subtle line movement
- node activation
- gentle transitions
- controlled reveal animations
- scroll-based progression where useful
- restrained image movement

Avoid:
- excessive parallax
- flashy transitions
- constant floating animations
- animations that distract from reading

## Overall Principle

Every visual element should feel intentional.

The portfolio should visually communicate:
"I understand complexity, structure it, build something from it, and make it work."
